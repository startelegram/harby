# Green Hat Platform - منصة القبعة الخضراء

منصة متخصصة في الأمن السيبراني والأدوات المتقدمة مع واجهة مستخدم جذابة وتصميم احترافي.

## الميزات الرئيسية

- **تصميم احترافي**: واجهة مستخدم جذابة بتصميم داكن وعناصر متحركة.
- **نظام عضوية متكامل**: تسجيل دخول، تسجيل مستخدمين جدد، لوحة تحكم للمستخدم.
- **صلاحيات المشرف**: إدارة المستخدمين، التعليقات، والتخفيضات.
- **أدوات متخصصة**: تحليل الثغرات، تشفير الملفات، هجمات DDoS، وغيرها.
- **نظام دفع**: دعم العملات المشفرة والطرق الإلكترونية.
- **نظام إشعارات متكامل**: إشعارات احترافية بدلاً من النوافذ المنبثقة.
- **اختبار الأمن السيبراني**: اختبار للمستخدمين الجدد لإثبات خبرتهم.
- **نظام المكافآت والتحديات**: تحديات وإنجازات للمستخدمين.
- **نظام التعليقات**: تعليقات المستخدمين مع موافقة المشرف.
- **محاكاة التحويلات**: عرض تحويلات وهمية لإضفاء الواقعية.

## التقنيات المستخدمة

- HTML5 / CSS3 / JavaScript
- Bootstrap 5 RTL
- Font Awesome 6
- Chart.js
- CryptoJS
- Particles.js

## كيفية الاستخدام

1. قم بفتح ملف `index.html` في متصفح الويب.
2. يمكنك تسجيل الدخول باستخدام حساب المشرف:
   - اسم المستخدم: `admin`
   - كلمة المرور: `@Black_00`
3. أو يمكنك إنشاء حساب جديد والمرور باختبار الأمن السيبراني.

## ملاحظات هامة

- هذا المشروع مصمم للعرض والتعلم فقط.
- جميع البيانات تُخزن محلياً في متصفح المستخدم (localStorage).
- لا يوجد اتصال بقاعدة بيانات خارجية أو خادم خلفي.
